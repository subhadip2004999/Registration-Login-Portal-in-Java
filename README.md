# Registration Login Portal (Java)

A simple Registration and Login portal implemented in Java with HTML front-end pages. This repository contains the source code (Java) and the HTML views used for the UI.

## Repository structure

- .classpath, .project, .settings — IDE project files (Eclipse)
- build/ — build output (if any)
- src/ — Java source code

The repository is primarily Java (≈92.7%) with some HTML views (≈7.3%).

## Features

- User registration form
- User login form
- Basic form validation and user flow (register → login)

## Prerequisites

- Java Development Kit (JDK) 8 or newer
- An IDE such as Eclipse or IntelliJ IDEA

## Setup & Run

1. Clone the repository:

   git clone https://github.com/subhadip2004999/Registration-Login-Portal-in-Java.git

2. Import the project into your IDE (Eclipse: File → Import → Existing Projects into Workspace).

3. Build and run:
   - If this is a standard Java application with a `main` class, run the main class from your IDE.
   - If this is a web/servlet application, deploy the project to a servlet container (Tomcat/Jetty) or run it using your IDE's server run configuration.

4. Open the HTML pages in a browser or navigate to the application URL if running on a server.

## Tests

No automated tests are included in the repository at this time. You can add unit tests (JUnit) under a `test/` directory and configure your build accordingly.
